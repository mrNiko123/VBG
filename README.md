# openboard для Android и iOS

Мобильная версия openboard: тот же клиент для любого OpenAI-совместимого API (OpenRouter, NVIDIA NIM, OpenAI, Groq, Ollama, свой `base_url`).
Это веб-приложение (`www/`), которое упаковывается в APK и IPA через Capacitor и работает как PWA.

## Что есть
- Выбор провайдера, смена API-ключа, **список моделей по вашему ключу** (`GET /models`), поиск и выбор модели.
- Стриминг ответа, кнопка «Стоп», markdown, блоки кода с копированием, несколько чатов.
- Учёт расхода по запросам, цены автоматически (OpenRouter) или вручную, **месячный бюджет**.
- Меню «+»: файлы и изображения (до 300 КБ текст / 5 МБ картинки), Skills, дизайн-система (тема и акцент, применяются сразу), веб-поиск.
- Вставка текста работает штатно (долгий тап → «Вставить»).

## Чего нет (по сравнению с ПК-версией)
Доступа к файлам и командам компьютера (агент), коннекторов MCP по stdio и Python-плагинов: на телефоне это технически невозможно.

## Как получить APK и IPA (без Android Studio и Xcode)
1. Создайте репозиторий на GitHub и загрузите в него содержимое этой папки.
2. Вкладка **Actions → Build openboard mobile → Run workflow** (или создайте тег `v1.0`).
3. Через 10–20 минут внизу страницы запуска появятся артефакты:
   - `openboard-android-debug-apk` → `app-debug.apk`;
   - `openboard-ios-unsigned-ipa` → `openboard-unsigned.ipa`.

**Android.** Скопируйте APK на телефон и установите (разрешите установку из неизвестных источников).
Для подписанного release-APK добавьте секреты `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`.

**iOS.** IPA собирается **без подписи**: Apple не разрешает ставить непроверенные приложения иначе. Варианты:
- Sideloadly или AltStore с бесплатным Apple ID: приложение работает 7 дней, потом переустановка.
- Платный аккаунт Apple Developer: подпишите IPA своим сертификатом или выложите в TestFlight (подпись добавляется в Xcode).

## Локальная сборка
- Android: `scripts/build-android.sh` или `scripts/build-android.bat` (Node 18+, JDK 17, Android SDK).
- iOS: `scripts/build-ios.sh` (только macOS, Xcode, CocoaPods).

## Запуск без установки (PWA)
Выложите папку `www/` на любой HTTPS-хостинг (GitHub Pages, Netlify, Cloudflare Pages).
iPhone: Safari → «Поделиться» → «На экран Домой». Android: Chrome → «Установить приложение».
Локально: `npm run serve`, затем http://localhost:8080.

## Важно знать
- **CORS.** В браузере/PWA запросы идут напрямую к провайдеру. OpenRouter, OpenAI и Groq разрешают это. Для NVIDIA NIM и подобных включите в настройках **«Нативные запросы»** (только APK/IPA): ответ приходит целиком, без потоковой печати.
- **Веб-поиск** (DuckDuckGo без ключа) и загрузка страниц работают только в APK/IPA: браузер блокирует такие запросы. Парсер поиска проверен на образце страницы, а не на живом сервисе; если DuckDuckGo изменит разметку, поиск перестанет находить результаты.
- **Ключ API** хранится в локальном хранилище приложения на устройстве, открытым текстом. Не устанавливайте приложение на чужие устройства.
- Для Ollama по локальной сети нужен `OLLAMA_ORIGINS=*`; на iOS адрес `http://` требует отдельного исключения ATS в `Info.plist`.
- История чатов хранится в `localStorage` (около 5 МБ): картинки в историю не сохраняются, только имена файлов.

## Проверка кода
`npm test`: 15 проверок ядра (поток, tool calls, markdown, цены, веб-инструменты) и дымовой тест интерфейса на локальном сервере.
Это не заменяет проверку на устройстве.
